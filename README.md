# get-shit-done
a personal kanban board that uses locally-stored json data as backup.
- editable columns, task cards, labels, comments
- configurable priority labels, resource links and subtask checklists
- dark and light mode
- all entry data can be saved locally to a json file. if browser cache cleared, user can re-load data from json
----------

Note: USE AT YOUR OWN RISK. this was generated by Google Gemini via several iterative prompts. I wanted to build this so that I could track my own personal projects without needing to pay a subscription fee and host my personal thoughts and info on someone else's server.
